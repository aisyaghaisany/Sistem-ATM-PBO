# Sistem ATM

## Deskripsi Project
Sistem ATM merupakan aplikasi berbasis Java yang dibuat untuk memenuhi tugas Ujian Akhir Semester (UAS) mata kuliah Pemrograman Berorientasi Objek (PBO).

Aplikasi ini dibuat untuk menggambarkan sistem layanan ATM yang melibatkan pengelolaan nasabah, rekening, dan transaksi.

## Konsep Pemrograman Berorientasi Objek

Project ini menggunakan konsep Pemrograman Berorientasi Objek (OOP) dalam pengembangan aplikasi. Konsep yang digunakan disesuaikan dengan implementasi pada setiap class.

## Cara Menjalankan Program

1. Clone repository ini ke komputer.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan Java Development Kit (JDK) sudah terpasang.
4. Buka folder `src`.
5. Compile dan jalankan class utama program sesuai konfigurasi project.

## Tujuan Project

Project ini bertujuan untuk menerapkan konsep Pemrograman Berorientasi Objek menggunakan bahasa Java melalui pembuatan aplikasi sistem ATM.
